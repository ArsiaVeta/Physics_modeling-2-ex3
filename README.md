# Задача 3. Кольца Ньютона

Моделирование интерференционной картины колец Ньютона для плоско-выпуклой
линзы радиуса кривизны R на плоской стеклянной пластине. Поддерживается
монохроматическое и квазимонохроматическое освещение с произвольной
центральной длиной волны λ₀ и шириной спектра Δλ.

## Физика

Толщина воздушного зазора: `d(r) ≈ r²/(2R)`.
С учётом π-сдвига фазы при отражении от плотной среды:

```
I(r, λ) = 4·I₀·sin²( π·r² / (λ·R) )
```

- центральная точка всегда тёмная;
- радиусы тёмных колец: `r_m = √(m·λ·R)`, m = 0, 1, 2, …
- для гауссова спектра шириной Δλ число различимых колец
  `m_max ≈ λ₀/Δλ`, длина когерентности `L_c = λ₀²/Δλ`.

Цветовая визуализация: каждой длине волны сопоставляется RGB по
кусочно-линейному алгоритму Bruton'а; для квазимонохроматического
света вклады разных λ суммируются с весами гауссова спектра.

## Параметры по умолчанию

| параметр | значение |
|---|---|
| радиус кривизны R | 1 м |
| область отображения | ±5 мм |
| разрешение | 800 × 800 пикс. |
| число узлов в спектре | 81 |
